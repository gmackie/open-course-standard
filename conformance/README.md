# Conformance fixtures

The `tests/` suite exercises strict parser behavior, unsafe path rejection, the four education contexts, identity checks for local imports, and a prototype lock integrity round-trip. The `examples/` directory contains positive fixtures.

Future dedicated fixture sets will cover negative schemas, real Git gitlinks, monorepos, dependency diamonds/cycles, malicious remotes and symlinks, reproducible packaging, privacy-preserving learner snapshots, signatures, LTI, and MCP authorization. The current tests are **not** an OCS certification suite.
