# Governance (provisional)

The current Git repository is the public proposal and implementation workspace. Maintainers review pull requests; this is **not** an IETF, ISO, W3C, or 1EdTech standards-track process.

RFC lifecycle: **Proposal -> Draft -> Candidate -> Stable -> Deprecated/Withdrawn**. Only Stable RFCs can define normative conformance of a released OCS version. Early 0.1 drafts express proposed requirements and may change incompatibly.

A Candidate RFC needs a problem statement, specification, conformance tests, security/privacy considerations, compatibility story, and at least one independent implementation or implementability review. Changes to stable wire or file formats require migration rules and compatibility notes. Disagreements should be recorded as alternatives instead of silently discarded.

Issue/PR discussion is public and must not contain private student information. Protected assessment content must never be added to this repository.
